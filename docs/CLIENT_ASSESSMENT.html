CRITICAL BUGS (10)

#1 – Multi-Property Square Footage Not Calculated
CRITICAL 2h
6 properties × 1,200 SQ ft should calculate 7,200 SQ ft total, but system only uses 1,200 SQ ft. Results in ~$3.6M construction cost underestimate.
Impact: Developers submit packages with incorrect costs to lenders
#2 – File Upload Errors Not Shown
CRITICAL 2h
Site photo and concept drawing upload failures logged to console only. Users believe upload succeeded.
Impact: Silent upload failures, user confusion
#3 – Insurance Data Sync Mismatch
CRITICAL 2h
Executive Summary shows "0 of 4 obtained" even when all four insurance types marked obtained in Risk Assessment. Data structure mismatch.
Impact: Lenders see incorrect insurance status
#4 – ROI Shows 0% With Positive Profit
CRITICAL 2-3h
Deal with $703,000 profit shows 0% ROI and "Weak" when developer equity is zero. Cascades to Cash-on-Cash and Sensitivity metrics.
Impact: Misleading financials sent to lenders
#11 – Section Save Error Not Shown (HIGHEST PRIORITY)
CRITICAL 1h
When section save fails, only logged to console. User has no way to know changes didn't persist. Users can spend 2+ hours filling forms thinking work is saved when it's lost.
Impact: DATA LOSS RISK – Users lose hours of work
#12 – Dashboard Load Error Not Shown
CRITICAL 1h
Dashboard fetch failures not shown. User sees empty projects list without explanation.
Impact: User thinks they have no projects when it's a database error
#17 – Project Fetch Error Not Shown
CRITICAL 1h
Project load failures result in silent redirect to dashboard with no error message.
Impact: User confused, thinks app is broken
#18 – Auth State Race Condition
CRITICAL 2h
getSession() and listener fire simultaneously, causing redundant state updates or missed initial auth state.
Impact: Auth errors, stuck loading states on page load
#22 – Unrecoverable ErrorBoundary
CRITICAL 1h
Once error caught, no way to reset state. Users stuck on error screen until page refresh.
Impact: Users can't recover from any error without refresh
#25 – Fire-and-Forget Saves (DATA LOSS RISK)
CRITICAL 2h
useAutoSave calls onSaveRef.current() without awaiting in beforeunload/unmount. Browser may close before save completes.
Impact: User loses recent changes if tab closes during auto-save
#30 – Unhandled Promise Rejection in Export
CRITICAL 1.5h
Promise.all() chain doesn't catch nested callbacks. Export can fail with cryptic error.
Impact: PDF/Excel export fails unexpectedly
