CATEGORY 2: Data Integrity (3 bugs)

🔴 BUG #1: Multi-Property Square Footage Not Calculated
Severity: CRITICAL
Effort: 2 hours
Code Location: ProjectScopeForm.tsx
Impact: Construction costs severely undersized

Example: Developer enters 6 properties at 1,200 SQ ft each
Expected: 7,200 SQ ft total
Actual: 1,200 SQ ft used
Result: Lender receives package with ~$3.6M cost underestimate

🔴 BUG #3: Insurance Data Sync Mismatch
Severity: CRITICAL
Effort: 2 hours
Code Location: ExecutiveSummaryForm.tsx:339-341
Impact: Shows "0 of 4" even when all marked

RiskAssessmentForm stores insurance fields as individual fields. ExecutiveSummaryForm looks for nested object with different names. Result: Insurance summary always shows 0 obtained.

🔴 BUG #4: ROI Shows 0% When Deal Has Profit
Severity: CRITICAL
Effort: 2-3 hours
Code Location: calculations.ts:239
Impact: Confusing financial metrics to lenders

Example: Deal shows $703,000 profit but 0% ROI and "Weak" deal strength. Root cause: When developer equity is 0, ROI formula returns 0% regardless of profit.
