Data Integrity Issues (Bugs #1, #3-4)

🔴 BUG #1: Multi-Property Square Footage Not Calculated
CRITICAL 2h
When a developer enters multiple properties with individual square footages, the system does not calculate the total. For example, entering 6 properties at 1,200 SQ ft each should create a total of 7,200 SQ ft, but the system only uses 1,200 SQ ft.
Impact Construction costs severely undersized (~$3.6M underestimate)
Code Location ProjectScopeForm.tsx + calculations.ts:161
Why it matters: Developers will submit packages with incorrect construction costs to lenders. This is a serious data integrity issue.
🔴 BUG #3: Insurance Data Sync Mismatch
CRITICAL 2h
Executive Summary shows "0 of 4 obtained" for insurance coverage, even when all four insurance types are marked as obtained in Risk Assessment. Data structure mismatch between forms.
Impact Summary shows incorrect insurance status
Code Location ExecutiveSummaryForm.tsx:339-341
Why it matters: Lenders rely on accurate insurance documentation. This error makes it appear insurance is not in place when it actually is.
🔴 BUG #4: ROI Shows 0% With Positive Profit
CRITICAL 2-3h
ROI calculates as zero when developer equity is zero, even though the deal has significant profit. Example: $703,000 profit shows as 0% ROI and "Weak" deal.
Impact Confusing/misleading financials to lenders
Code Location calculations.ts:239
Why it matters: Cascades to Cash-on-Cash and Sensitivity analysis metrics. Lenders see contradictory metrics ($700k profit but 0% ROI).
